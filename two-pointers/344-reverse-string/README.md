# 344. Reverse String

**Source:** https://leetcode.com/problems/reverse-string/ | **Topic:** two-pointers | **Difficulty:** Easy | **Solved:** 2026-07-25

## Approach
Two pointers start at both ends and swap characters while moving toward the middle, reversing the array
in place.

## Complexity
- Time: O(n)
- Space: O(1)
